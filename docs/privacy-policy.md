## 2. 정보 이용 목적

- **사진**: 사용자가 요청한 이모티콘 생성 작업 수행
- **API 키**: 사용자가 Google Gemini AI 서비스에 직접 요청을 보내기 위한 인증 토큰
- 위 외의 용도(마케팅, 분석, 광고 등)로는 **사용하지 않습니다**

---

## 3. 제3자 제공/위탁

- **Google LLC (Gemini API)**: 사용자가 입력한 사진은 이미지 생성을 위해 Google AI 서비스로 전송됩니다.
  Google의 데이터 처리방침: https://policies.google.com/privacy
- 위 외의 제3자에게는 **어떤 정보도 제공하지 않습니다**.

---

## 4. 데이터 보안

- API 키는 **Fernet (AES-128 + HMAC-SHA256)** 으로 암호화되어 기기 로컬에만 저장됩니다.
- 암호화 키는 기기의 고유 정보(PBKDF2-SHA256, 200,000 iter)에서 도출되어, 다른 기기로 파일을 복사해도 복호화할 수 없습니다.
- 사진은 처리 완료 후 자동 삭제되며, 사용자는 언제든 앱 내 [캐시 삭제] 기능으로 즉시 제거할 수 있습니다.

---

## 5. 사용자 권리

다음 권리를 행사할 수 있습니다:

- **열람**: 앱 내 우측 상단 ⚙ 메뉴에서 저장된 키 상태 확인
- **수정**: 같은 메뉴에서 새 키로 변경
- **삭제**: 같은 메뉴에서 [삭제] 클릭 → 즉시 제거
- **데이터 이동**: 생성된 ZIP은 사용자가 자유롭게 다운로드/공유

위 권리 행사를 위해 별도 문의가 필요한 경우 위 이메일로 연락 주세요.
