## 2. 정보 이용 목적

- **사진**: 사용자가 요청한 이모티콘 생성 작업 수행

- 위 외의 용도(마케팅, 분석, 광고 등)로는 **사용하지 않습니다**

## 3. 제3자 제공/위탁

### 3-1. Google LLC (Gemini API)
- **위탁 내용**: 사용자가 입력한 사진은 이미지 생성을 위해 Google AI 서비스로 전송됩니다.
- **전송 데이터**: 누끼 처리된 인물 사진 + 반려동물 사진, 텍스트 프롬프트
- **Google의 데이터 처리방침**: https://policies.google.com/privacy
- **사용 모델**: Gemini 2.5 Flash Image (이미지 생성), Gemini 2.5 Flash (분류·라벨)

### 3-2. Render (백엔드 호스팅)
- **위탁 내용**: 사진 임시 보관 및 처리
- **데이터 처리 위치**: 싱가포르 리전 데이터센터
- **보관 기간**: 처리 완료 후 24시간 이내 자동 삭제
- **Render 처리방침**: https://render.com/policies/privacy

### 3-3. 위 외의 제3자에게는 **어떤 정보도 제공하지 않습니다**.

## 4. 데이터 보안

- **API 키 암호화**: Fernet (AES-128 + HMAC-SHA256) 으로 암호화되어 기기 로컬에만 저장됩니다.
- **암호화 키 도출**: PBKDF2-SHA256 (200,000 iter) + 기기의 고유 정보 (호스트명, 사용자명, 설치 경로)
- **기기 잠금**: 다른 기기로 파일을 복사해도 복호화할 수 없습니다.
- **사진 자동 삭제**: 처리 완료 후 24시간 이내 자동 삭제
- **사용자 수동 삭제**: 앱 내 [캐시 삭제] 기능으로 즉시 제거 가능
- **HTTPS 통신**: 모든 백엔드 통신은 TLS 1.3 암호화
