  - 🖍 파스텔 (분필 가루 질감)
  - 📖 웹툰 (가는 펜선 + 큰 눈)
  - 🎮 픽셀아트 (16-bit 도트 그리드)
  - 🎭 팝아트 (하프톤 점무늬 + 4색)

• 원본 색상 보존
  옷·머리·털 색이 32장 모두 일관되게 유지

  stickers/ 폴더 + icon.png + manifest.json + README.txt 동봉

🔐 API 키 안전

본 앱은 사용자가 직접 Google AI Studio에서 무료로 발급받은
Gemini API 키를 입력하는 BYOK(Bring Your Own Key) 방식입니다.

• 키는 Fernet (AES-128 + HMAC) 으로 암호화되어 기기에만 저장됨
• 다른 PC/기기로 파일을 복사해도 복호화 불가
• 사용량은 Google이 키 소유자에게 직접 청구
• 본 앱은 광고/추적 없음

💰 비용 안내

• 앱 구매: 1회 ₩3,300 (평생 사용)
• Gemini API: 사용자 본인 부담
• 무료 티어 한도 안에서 일 95장까지 비용 0원
• 32장 생성에 약 7~12분 소요 (무료 티어 안전 속도)

🎨 활용 예시

• 내 강아지/고양이로 카카오톡 이모티콘 제작
• 가족 사진 + 반려동물 → 가족용 이모티콘 세트
• 좋아하는 캐릭터/인형 → 인형 캐릭터화
• 음식점 브랜드 마스코트 시안
• 라인/네이버 등 다른 플랫폼 스티커 제작에도 활용

## 💡 자주 묻는 질문 (FAQ) — 자세한 설명 부족 시 추가용

### Q1. 인터넷이 필요한가요?

A. 네. Google Gemini AI를 호출하므로 Wi-Fi 또는 모바일 데이터 필요합니다.

### Q2. 사진은 외부에 저장되나요?

A. 처리 중 임시로 백엔드 서버에 저장되며, 24시간 이내 자동 삭제됩니다.

### Q3. Gemini API 키는 어떻게 발급받나요?

A. Google AI Studio (https://aistudio.google.com/apikey) 에서 무료 발급 가능. 앱 첫 화면에서 단계별 안내합니다.

### Q4. 카카오톡에 바로 사용 가능?

A. 생성된 ZIP을 카카오톡 이모티콘 스튜디오에 제출 → 심사 통과 후 카카오 이모티콘 상점에 등록.

### Q5. 환불 가능?

A. Google Play 환불 정책 (구매 후 48시간 이내) 적용.
